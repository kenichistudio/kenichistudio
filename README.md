# 🎌 Kenichi Studio

> **Simple Tools. Powerful Stories.**

Kenichi Studio is a creative-first engineering lab dedicated to building accessible, high-performance tools for creators, developers, and storytellers.

## 🚀 The Suite

*   **[Kenichi Studio (Web)](...)**: Our flagship in-browser video editor. Create, animate, and export without a server.
*   **[Kenichi Desktop](...)**: A native powerhouse built with Rust and Tauri for maximum performance.
*   **[Kenichi Core](...)**: The framework-agnostic engine powering everything we build. Projections, transforms, and frame-perfect rendering.
*   **Kenichi Sparks**: A collection of micro-apps for focused creative utilities.

## 🛠️ Our Philosophy

1.  **Performance First**: We believe rendering should happen on the user's device, not a server.
2.  **Simplicity**: Professional power with a "simple" entry point.
3.  **Openness**: Building in public and contributing to the open-web video ecosystem.
